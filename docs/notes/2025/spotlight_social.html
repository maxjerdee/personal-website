Friends

A node Student, colored by class (nine classes across four subjects)
An edge A → B: A named B as a friend in the survey. One-way: a nomination need not be returned

Reported friendship network of 329 students in nine classes of a lycee in Marseille, France, December 2013. A directed edge i->j means student i named j as a friend in the survey. Collected by the SocioPatterns collaboration alongside wearable-sensor proximity, contact-diary and Facebook networks for the same school; this is the friendship survey. Mastrandrea, R., Fournet, J., & Barrat, A. (2015). Contact Patterns in a High School: A Comparison between Data Collected Using Wearable Sensors, Contact Diaries and Friendship Surveys. PLOS ONE 10(9), e0136497. Node attribute class is a readable name for each of the nine classes, with the original French preparatory-class code kept as class_code (a trailing * marks the selective stream of that subject); field collapses the nine into the four subjects they study.

SocioPatterns (R. Mastrandrea, J. Fournet, A. Barrat) · compiled by Max Jerdee · source · data and build script
