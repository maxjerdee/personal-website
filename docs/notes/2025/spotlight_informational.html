An edge A—B: customers who buy A also frequently buy B

Python Standard Library

A node Python standard library module or package
An edge A → B: module A imports module B at module level

Python 3.10.12’s own standard library import graph: a directed edge A->B means module A imports module B at module level, parsed directly from this interpreter’s installed stdlib source via the ast module – no external dataset. Modules that neither import, nor are imported by, any other stdlib module in this set are omitted.

data and build script

Licence. Built for this repository from the CPython standard library’s own import graph; module names and import relations only, no code. Covered by this repository’s own licence.

“Vehicle” WordNet

A node A WordNet synset (one sense of a word), colored by how far below “vehicle” it sits
An edge A → B: B is a more specific kind of A (e.g. car → convertible)

WordNet’s hypernym (IS-A) hierarchy under ‘vehicle.n.01’, depth 4: a directed edge parent->child means the child is a more specific kind of the parent (e.g. car -> convertible). A literal tree – WordNet itself allows a synset more than one hypernym (14 of these 301 genuinely have two or three, e.g. tank is both an armored vehicle and a tracked vehicle), but only the first in-pool one (WordNet’s own listed order) is kept as this synset’s edge, so every node has exactly one parent. depth/height are computed from this kept tree, truncated to depth <=4 by it (not by the wider hyponym search used to find candidates). Source: Princeton WordNet, via NLTK’s corpus interface.

source · data and build script

Licence. WordNet 3.0 licence (Princeton University): permissive, redistribution permitted with the copyright notice retained and attribution given.

npm Dependencies

A node An npm package, colored by its role here: hub, shared, used once, or consumer
An edge A → B: A lists B in its runtime dependencies, so installing A installs B

Runtime dependencies among 250 widely-used npm packages, from the public npm registry. A -> B means A lists B in its dependencies. Built by taking the 600 packages with the most dependents, computing the dependency edges among them, and keeping the 250 most connected as an induced subgraph.

source · data and build script

Licence. Public package metadata from the npm registry – package names and dependency relations only, no package contents.

Supreme Court Citations

A node A majority opinion of the U.S. Supreme Court, placed at the year it was decided and colored by its subject matter
An edge A → B: opinion A cites opinion B, so every edge points back in time

Citations among 250 of the most-cited opinions of the U.S. Supreme Court, from every volume of U.S. Reports. A -> B means opinion A cites opinion B; citations restricted to pairs within the set. The set is the largest connected component of the top 256 by citations received, so every case here cites or is cited by another. Case text and citation extraction: Caselaw Access Project (case.law). Subject-matter classification (issueArea): Supreme Court Database, H. J. Spaeth et al., supremecourtdatabase.org.

source · data and build script

Licence. Public domain. US court opinions carry no copyright, and the Caselaw Access Project states its bulk data is free of restrictions.
